# Платформа поддержки киберспортсменов
Учебный проект по разработке веб-платформы для поиска киберспортивных турниров и взаимодействия игроков, тренеров и менеджеров.

## Возможности
Планируемые возможности платформы:
- просмотр и фильтрация турниров;
- подача заявок на участие и отслеживание их статуса;
- профили игроков с указанием игр и игрового ранга;
- рекомендации турниров на основе профиля игрока;
- уведомления о новых турнирах и изменениях заявок;
- управление турнирами, командами и клубами;
- администрирование пользователей, ролей и справочников игр.

## Требования

### Функциональные требования

- Игрок имеет возможность зарегистрироваться, заполнить профиль, просматривать и фильтровать турниры, подавать заявки и следить за их статусом.
- Менеджер имеет возможность добавлять и редактировать турниры, проверять сведения о них, управлять заявками, командами и новостями.
- Администратор имеет возможность управлять учётными записями и ролями, модерировать данные, редактировать справочник игр и просматривать состояние сервисов.

### Нефункциональные требования

- Система должна поддерживать не менее 100 одновременных пользователей.
- Время загрузки основных страниц не должно превышать 2 секунд, время типового запроса к PostgreSQL — 200 мс.
- Резервное копирование PostgreSQL должно выполняться не реже одного раза в сутки. Redis используется для кэширования и временных данных.
- Доступ к функциям системы определяется ролью пользователя. Пароли хранятся в виде защищённых хешей, соединение с системой защищено.
- Веб-приложение должно работать в актуальных версиях основных браузеров и не требовать установки отдельного приложения.
- Сторонние библиотеки и материалы должны использоваться согласно условиям их лицензий; сведения о лицензиях указываются в документации проекта.

## Технологии
- **Frontend:** Vue.js 3
- **Сервис пользователей:** C#, ASP.NET Core Web API
- **Сервис турниров:** Python, FastAPI
- **База данных:** PostgreSQL
- **Кэширование:** Redis
- **Обмен сообщениями:** RabbitMQ
- **Контейнеризация:** Docker
