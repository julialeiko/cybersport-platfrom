# Платформа поддержки киберспортсменов
Учебный проект по разработке веб-платформы для поиска киберспортивных турниров и взаимодействия игроков, тренеров и менеджеров.

## Возможности
Планируемые возможности платформы:
- просмотр и фильтрация турниров;
- подача заявок на участие и отслеживание их статуса;
- профили игроков с указанием игр и игрового ранга;
- рекомендации турниров на основе профиля игрока;
- уведомления о новых турнирах и изменениях заявок;
- управление турнирами, командами и клубами;
- администрирование пользователей, ролей и справочников игр.

## Технологии
- **Frontend:** Vue.js 3
- **Сервис пользователей:** C#, ASP.NET Core Web API
- **Сервис турниров:** Python, FastAPI
- **База данных:** PostgreSQL
- **Кэширование:** Redis
- **Обмен сообщениями:** RabbitMQ
- **Контейнеризация:** Docker
